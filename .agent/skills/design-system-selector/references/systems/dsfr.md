# DSFR — Système de Design de l'État Français (DINUM)

> Portails ministériels, démarches en ligne FR | Stack : Vanilla JS, SCSS, Web Components

## Construction
- Vanilla JS, SCSS, Web Components. Conforme RGAA strict.
- Charte Marianne, composants accessibles documentés.

## Projets cibles
**Service Public / Santé / Citoyenneté** — alternative FR à Gov.uk, obligatoire pour services publics français.

## Particularité clé
Conformité RGAA, référence française a11y, usage réglementaire.
