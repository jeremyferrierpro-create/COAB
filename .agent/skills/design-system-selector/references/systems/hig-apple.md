# Human Interface Guidelines (HIG) — Apple

> Design System — iOS, macOS, watchOS, visionOS | Stack : SwiftUI, UIKit, AppKit

## Construction
- Principes Apple : clarté, déférence, profondeur. Grille, typographie SF Pro/SF Symbols, icônes.
- Animations spring physics, matériaux de profondeur, spatial computing visionOS.

## Projets cibles
Applications natives Apple, apps grand public exigeant conventions OS natives. Alternative à Material 3 pour mobile-first.

## Particularité clé
Physique des ressorts, continuité tactile, gestion de la profondeur spatiale (visionOS).
