# Fluent 2 — Microsoft

> Design System — Windows 11, Office 365, Teams, Azure | Stack : React, React Native, Web Components

## Construction
- Matériaux signature : Acrylic (glassmorphisme maîtrisé), Mica. Tokens DTCG, Web Components.
- Micro-interactions subtiles, alignement multi-plateforme (iOS, Android, Web).

## Projets cibles
Bureautique, suites productives, apps multi-OS nécessitant cohérence Windows/Office.

## Particularité clé
Acrylic Material (backdrop-filter maîtrisé sans dégrader GPU si bien dosé), intégration bureautique.
