# Material Design 3 (Material You) — Google

> Design System de production — Mobile/Web/Cloud | Stack : Web Components, Flutter, Jetpack Compose, Angular

## Construction
- Fondations DTCG (colors, typography scale, spacing grid 4/8px, shadows Z, border-radius, breakpoints, animation curves)
- Pipeline Style Dictionary → CSS vars (`--md-sys-color-primary`), TS tokens, config Tailwind
- Composants headless + stylisés documentés Storybook, testés axe-core/Chromatic

## Projets cibles
Android, Web mondial, Wearables, Cloud Google. Recommandé pour **Application Mobile-First Grand Public** (Semi-Flat / Minimalisme tactile).

## Particularité clé
**Dynamic Theming** : extraction de palette à partir du fond d'écran utilisateur (Material You). Système de couleur le plus automatisé du marché.
